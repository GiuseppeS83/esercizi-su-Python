# Conversione da Celsius a Fahrenheit

Converte una temperatura da gradi Celsius a gradi Fahrenheit.

## Come funziona

Applica la formula `F = C * 9/5 + 32`. Accetta anche numeri decimali.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Conversione_da_Celsius_a_Fahrenheit.py
```

## Esempio di esecuzione

```text
Inserisci la temperatura in Celsius:36.6
 Temperatura in Fahrenheit: 97.88000000000001
```
