# Moltiplicazioni senza usare l'operatore

Moltiplica due numeri interi senza usare l'operatore `*`.

## Come funziona

Somma il primo numero a se stesso `M` volte con un ciclo `for` (la moltiplicazione come somma ripetuta).

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Moltiplicazioni_senza_usare_l_operatore.py
```

## Esempio di esecuzione

```text
Inserisci il primo numero: 6
Inserisci il secondo numero: 7
Il primo numero è: 6
Il secondo numero è: 7
Il risultato è: 42
```

## Note

Pensato per `M` intero positivo: con `M` uguale a 0 o negativo il risultato è 0.
