# Inverti una stringa

Stampa una stringa scritta al contrario.

## Come funziona

Scorre l'indice dall'ultimo carattere al primo e costruisce la nuova stringa carattere per carattere.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Inverti_una_stringa.py
```

## Esempio di esecuzione

```text
Inserisci il nome: Claude
edualC
```
