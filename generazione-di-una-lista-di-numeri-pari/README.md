# Generazione di una lista di numeri pari

Genera la lista dei numeri pari compresi tra 1 e N.

## Come funziona

La funzione `numeri_pari(n)` scorre i numeri da 1 a `n` e aggiunge alla lista quelli con `i % 2 == 0`; la lista viene poi stampata.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Generazione_di_una_lista_di_numeri_pari.py
```

## Esempio di esecuzione

```text
Inserisci un numero intero: 15
La lista dei numeri pari tra 1 e 15 è: [2, 4, 6, 8, 10, 12, 14]
```
