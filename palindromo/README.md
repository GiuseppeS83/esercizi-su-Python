# Palindromo

Verifica se una stringa è palindroma, cioè se si legge uguale da sinistra a destra e da destra a sinistra.

## Come funziona

Usa due indici, uno all'inizio e uno alla fine, che si avvicinano al centro confrontando i caratteri. Al primo carattere diverso si ferma.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Palindromo.py
```

## Esempio di esecuzione

```text
Inserisci una stringa: anna
La stringa è palindroma
```

## Note

Il confronto distingue maiuscole e minuscole e considera spazi e punteggiatura ("Anna" non risulta palindroma).
