# Conteggio delle vocali in una stringa

Conta quante vocali contiene una stringa.

## Come funziona

La funzione `conta_vocali(s)` controlla ogni carattere e incrementa un contatore se è presente in `aeiouAEIOU`.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Conteggio_delle_vocali_in_una_stringa.py
```

## Esempio di esecuzione

```text
inserisci una stringa:Ciao mondo
il numero di vocaliin Ciao mondo è: 5
```

## Note

Le vocali accentate (à, è, ì, ò, ù) non vengono contate. Nel messaggio finale manca uno spazio in "vocaliin".
