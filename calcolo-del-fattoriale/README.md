# Calcolo del fattoriale

Calcola il fattoriale di un numero intero, `n!`.

## Come funziona

Moltiplica `fattoriale` per ogni numero da 1 a `n` con un ciclo `for`.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Calcolo_del_fattoriale.py
```

## Esempio di esecuzione

```text
Inserisci un numero:5
Il fattorialeè: 1
Il fattorialeè: 2
Il fattorialeè: 6
Il fattorialeè: 24
Il fattorialeè: 120
```

## Note

**Nota:** il `print` è dentro il ciclo, quindi viene mostrato il valore a ogni passaggio e non solo il risultato finale (che è l'ultima riga). Nel messaggio manca uno spazio in "fattorialeè".
