# Calcolo della potenza

Calcola la potenza di un numero, cioè `base ^ esponente`, senza usare l'operatore `**`.

## Come funziona

Parte da `risultato = 1` e, con un ciclo `for` ripetuto `esponente` volte, moltiplica il risultato per la base.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Calcolo_della_potenza.py
```

## Esempio di esecuzione

```text
Inserisci la base: 2
Inserisci l'esponente: 10
La potenza è: 1024
```

## Note

Funziona con esponenti interi non negativi. Con esponente 0 il risultato è 1.
