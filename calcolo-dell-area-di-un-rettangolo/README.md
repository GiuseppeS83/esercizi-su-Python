# Calcolo dell'area di un rettangolo

Calcola l'area di un rettangolo a partire da lunghezza e larghezza.

## Come funziona

Moltiplica lunghezza e larghezza (`area = lunghezza * larghezza`). Accetta anche numeri decimali.

## Requisiti

- Python 3 (nessuna libreria esterna)

## Esecuzione

```bash
python Calcolo_dell_area_di_un_rettangolo.py
```

## Esempio di esecuzione

```text
Inserisci la lunghezza5
 Inserisci la larghezza:3.5
L'area del rettangolo è:  17.5
```
